# TIDELOCK — Asset Licences

Every binary asset committed to this repository must have a record here. CI
(`pnpm lint:assets`) fails the build if a model, texture, HDR or KTX2 file in
`public/assets/` has no entry, so this file cannot silently drift.

## Rules

1. Only redistributable assets are committed. If a licence forbids
   redistribution, the asset is fetched or generated by a script instead and the
   script is committed, not the asset.
2. Preferred sources, in order: assets authored for this project, CC0
   (e.g. Poly Haven), then other clearly permissive licences.
3. No scraped or unattributed assets. Ever.
4. Mixamo characters and animations may be used in a game under Adobe's terms,
   but raw source-asset redistribution is a separate question from use. Any
   Mixamo-derived content is imported through a documented pipeline and recorded
   here with its transformation, rather than committed as an opaque library.
5. Every record states: file, type, source, author, licence, and any
   transformation applied.

## Generated, not committed

These trees are produced by a committed script and are excluded from version
control. This is rule 1 in action: the licence forbids redistribution, so the
repository ships the generator rather than the output.

`pnpm lint:assets` exempts them from per-file attribution records and, in
`checkGeneratedTreesAreIgnored`, asserts that each one really is in `.gitignore`
— so the exemption cannot be used to smuggle an unattributed binary into a public
repository.

| Tree | Type | Produced by | Redistributable | Notes |
| --- | --- | --- | --- | --- |
| `public/assets/audio/dialogue/` | Dialogue voice-over (MP3) and subtitle cues (WebVTT) | `pnpm generate:vo` | **No** | Synthesised by `edge-tts`, an unofficial client for Microsoft Edge's online speech service. See below. |

### Why the voice-over is not committed

`edge-tts` documents its own usage but grants no commercial voice-output licence,
and the audio it returns is generated by a Microsoft service whose terms do not
permit redistribution (master spec §20.5). Committing it to a public MIT-licensed
repository would breach both rule 1 and rule 3 of this document.

So the pipeline is the deliverable:

- `scripts/vo/generate_vo.py` — the generator, committed.
- `content/voices/cast.json` — the voice direction, committed. Ours.
- `content/dialogue/vo-manifest.json` — the ledger, committed. Ours: it records
  what was generated from what, and its `sourceHash` values are what make
  regeneration incremental.
- The MP3 and VTT files — **not** committed. Reproduce with `pnpm generate:vo`.

Consequences worth stating plainly rather than discovering later:

1. **The GitHub Pages build ships without voice-over.** Dialogue still plays:
   every node carries an authored `duration`, and subtitles are driven from the
   authored text, so the campaign is completable and readable silently. Voice is
   an enhancement on a local or self-hosted build until the provider is replaced.
2. **CI does not synthesise.** Spec §20.4 forbids `build` from regenerating
   hundreds of TTS files on every run. `pnpm vo:check` is the CI-safe gate: it
   verifies the manifest matches the authored dialogue using hashes alone, with
   no network access.
3. **The provider is replaceable by design.** Everything provider-specific lives
   behind `SpeechBackend` in the pipeline. An offline, open-weight model with a
   compatible licence can be dropped in without touching the manifest format, the
   cast configuration, or anything in `src/` — at which point the generated audio
   becomes committable and this section can be revised.

Before any commercial release, the applicable service and voice terms must be
verified, or the backend swapped for one whose licence permits distribution.

## Fonts

The UI currently uses system font stacks only (see
`src/ui/styles/tokens.css`), so no font files are committed and no font licence
applies. If a webfont is added later it must be recorded here with its licence
and the subset applied.

## Audio

No audio committed yet.

Generated dialogue audio will be produced at build time by the voice pipeline
and is not a third-party asset. The generator itself (`edge-tts`) is an
unofficial client for an online Microsoft speech service: it does not grant a
commercial voice-output licence, so it is used for development placeholder
generation only and sits behind a replaceable adapter. Service and voice terms
must be reviewed before any commercial distribution.

## Verification

```bash
pnpm lint:assets
```

Checks that every asset requiring attribution appears in this file, that no
texture exceeds the 4096 px budget, that GLB and KTX2 containers parse, that no
oversized uncompressed audio sits in the runtime tree, and that no content file
contains placeholder text.

## Godot harbor edition

The active Godot game's harbor geometry, icon (`godot/icon.svg`), UI art and
synthesized sound are original procedural source assets under this repository's
MIT licence. The first-person edition uses the CC0 libraries listed below. No generated speech is included.

`godot/fonts/FieldSans.ttf` is the unmodified **DejaVu Sans** font from the Debian
`fonts-dejavu-core` package. Source: https://dejavu-fonts.github.io/. Original
Bitstream Vera copyright applies; DejaVu changes are public domain. The full
redistribution notice is in `godot/fonts/LICENSE.txt` and included in the web
build's `LICENSES.txt`. The Godot runtime is MIT-licensed; its licence is included
as `GODOT_LICENSE.txt` in the web build and attributed in the in-game credits.
